# Industry Blueprints

A catalog of personas, use cases, processes, app experiences, and AI agent skills for industry-grade public-sector software.

This is the knowledge layer. The [Industry Modules platform](https://github.com/industry-blueprints/platform) is the working proof — every blueprint here links to the exact real code, config, or running feature that backs it.

## Local development

```
bundle install
bundle exec jekyll serve
```

Site builds via GitHub Pages' built-in Jekyll pipeline (no custom Actions workflow) — see `Gemfile`.
